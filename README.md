# Framelet public information site

This repository contains only the public static website for Framelet's privacy policy, terms, support, and links to WebM third-party source archives. It does not contain the private Framelet application source.

GitHub Pages publishes the root of `main`. No framework, tracker, build script, or external asset is required.

Pages: `index.html`, `privacy.html`, `terms.html`, `support.html`, `third-party-sources.html`.
