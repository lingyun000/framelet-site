常见问题

启动后为什么没有主窗口？

Framelet 默认从菜单栏与快捷键使用。点击菜单栏图标可截图、打开设置、帮助与结果；关闭辅助窗口不影响截图。

截图是黑色或提示权限？

打开“设置 → 权限”，按引导检查系统屏幕录制授权。macOS 提示重新打开时再重新打开 App。受保护内容可能无法捕获；不要删除 App 或重置全部系统权限。

快捷键没有反应？

可能与其他 App 冲突。从菜单栏重试注册，或在“设置 → 截图”录入新组合键；菜单栏的区域截图入口仍可使用。

只能选到整窗怎么办？

右键开启悬停识别并等待结果；辅助功能、App 提供的边界与可见内容都会影响识别。没有可靠子元素时使用整窗或手动拖选，不保证所有 App 都有可识别子内容。

滚动长图拼接失败？

选同一窗口内的正文，慢慢滚动并检查预览；动态内容、固定栏和重绘会影响拼接。按提示回滚到已验证位置，或完成保留已截内容。Esc 一次暂停、第二次取消。

录屏没有人声，GIF 没有声音？

开始前开启麦克风并选对设备，确认系统麦克风权限。GIF 格式不支持音频；需要声音请选择 MP4、MOV 或带音轨的 WebM。

WebM 导出失败？

发行候选包内置编码器，不要求用户安装 FFmpeg。可重试或改选 MP4/MOV/GIF；编辑保留。反馈时提供版本、格式与错误摘要，不附私人原片。

翻译为什么不可用？

可用方式随 macOS 和语言包变化。检查系统支持和语言包；网页备用需主动选择，再自行粘贴原文，不会自动提交。

内容会被上传吗？

截图、录屏与 OCR 在本机处理，没有开发者素材上传服务。系统翻译、网页翻译、Apple 购买与 GitHub 支持另有对应服务政策，详见隐私政策。

如何管理订阅或申请退款？

当前订阅购买和限额尚未开放，不承诺测试价格或免费试用。实际开放后由 Apple 购买页显示条款；管理续订用 Apple 订阅页，退款用 Apple 问题报告页。

反馈时请提供

  • Framelet 版本与构建号（设置 → 关于）。
  • macOS 版本、Mac 芯片、显示器数量与缩放设置。
  • 功能入口、操作步骤、预期结果和实际错误摘要。
  • 可以复现的虚构示例；日志只提供经检查的必要摘要。
GitHub 反馈需要账号，内容公开。不要上传私人截图、录屏、OCR 文本、原始日志、账号或支付凭证。敏感问题先只描述现象，再请求私密联系渠道。

Common questions

Why is there no main window?

Framelet starts in the menu bar and works through shortcuts. Click its icon to capture, open Settings or Help, or restore results. Closing auxiliary windows does not disable capture.

Why is my capture blank or permission blocked?

Check Screen Recording through Settings → Permissions. Reopen the app if macOS requests it. Protected content may be unavailable. Do not delete the app or reset all system permissions.

Why does the shortcut do nothing?

It may conflict with another app. Retry registration from the menu bar or change it in Settings → Capture. Capture Region remains available from the menu bar.

Why can I only select a whole window?

Right-click to enable hover detection and wait for results. Accessibility access, exposed boundaries and visible content affect detection. Use a window or manual region when reliable elements are unavailable.

What if a scrolling capture fails?

Select the main content of one window, scroll slowly and check the preview. Dynamic content, sticky bars and repainting affect stitching. Return to a confirmed position or finish with the captured portion. Esc pauses once and cancels on the second press.

Why is voice missing, or my GIF silent?

Enable the microphone, choose the right device and check macOS permission before starting. GIF has no audio; use MP4, MOV or WebM with an audio track.

What if WebM export fails?

The release candidate bundles its encoder; users do not need to install FFmpeg. Retry or choose MP4/MOV/GIF; edits are kept. Include the version, format and error summary in feedback, without private source media.

Why is translation unavailable?

Availability depends on macOS and language packs. Check system support and installed languages. The optional web fallback requires your action and manual pasting; text is not submitted automatically.

Is my content uploaded?

Screenshots, recordings and OCR are processed locally, without a developer-operated content upload service. System translation, web translation, Apple purchases and GitHub support have their own policies; see Privacy.

How do I manage subscriptions or request a refund?

Subscription purchases and limits are not currently enabled; test prices or trials are not promised. When available, Apple’s purchase sheet shows the terms. Use Apple’s subscription page for renewal management and Report a Problem for refund requests.

What to include in feedback

  • Framelet version and build (Settings → About).
  • macOS version, Mac chip, display count and scaling.
  • Feature entry, steps, expected outcome and observed error summary.
  • A fictional reproducible example; only necessary, reviewed log excerpts.
GitHub requires an account and feedback is public. Do not upload private screenshots, recordings, OCR text, raw logs, account details or payment records. For sensitive issues, describe only the symptom and request a private contact method.
