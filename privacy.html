隐私政策 / Privacy Policy

更新日期 / Updated: 2026-09-29 · 适用于 Framelet macOS App / Applies to the Framelet macOS app

中文

我们处理的信息

Framelet 在你授权并主动使用功能时，可读取屏幕、其他应用窗口的可访问性信息，以及你启用麦克风后录制的声音。截图、录屏、OCR 文字、翻译工作区、标注和导出在 Mac 上处理。应用不会把这些素材自动上传到 Framelet 开发者的服务器；目前没有开发者运营的素材云同步、广告或行为分析服务。

本地保存

你保存或导出的图片、视频、GIF 和文字位于你选择的位置；新录制输出默认位于 ~/Movies/Framelet/。应用还会在本机保存语言、权限相关设置、保存目录和功能偏好。若启用订阅额度，额度记录位于本机 SQLite 数据库，完整性密钥存于 macOS 钥匙串；记录不包含截图像素或 OCR 原文。滚动截图会在用户 Library 下的 Logs/Framelet/Scrolling/（沙盒版位于 App 容器中）写入有限的诊断事件，不记录画面像素、页面文字或按键；只有你主动启用失败帧调试时，该目录才会额外保存失败画面 PNG。你可以在 Finder 中管理自己保存的文件及这些本地日志。

外部服务与主动操作

若订阅功能开放，商品展示、购买、续订及恢复由 Apple StoreKit 和你的 Apple 账户处理；开发者不接收支付卡号。某些系统版本无法直接翻译时，只有你点击网页翻译选项，应用才会复制原文并打开 Google 翻译首页；应用不会自动把原文附在网址中或替你提交。你之后手动粘贴到第三方网站的内容，受该网站自己的隐私政策约束。

网站与支持

本网站由 GitHub Pages 托管，访问网站时 GitHub 可能按照其隐私声明处理访问数据。本网站不嵌入第三方分析脚本。通过公开 GitHub Issue 反馈时，你提交的内容会公开；请勿发布截图、录屏、账号、交易凭证或其他敏感信息。

你的选择与联系

你可以在 macOS 系统设置中撤销屏幕录制、辅助功能或麦克风权限，在 App 中停止使用相应功能，并管理本地保存的文件。订阅可在 Apple 账户的订阅管理页面管理。有关本政策的问题可通过支持页面联系开发者。实际发行版如更改数据处理方式，我们会更新本页及 App Store 隐私信息。

English

Information processed

With your permission and when you use a feature, Framelet can access your screen, accessibility information from other apps' windows, and microphone audio if you enable it. Screenshots, recordings, OCR text, translation workspaces, annotations, and exports are processed on your Mac. The app does not automatically upload this content to a Framelet developer server. It currently has no developer-operated content sync, advertising, or behavioral analytics service.

Local storage

Images, videos, GIFs, and text you save or export remain in locations you choose; new recordings default to ~/Movies/Framelet/. The app also stores language, permission-related settings, save locations, and feature preferences locally. If subscription quotas are enabled, a local SQLite database holds usage records and macOS Keychain holds an integrity key; the records contain no screenshot pixels or OCR text. Scrolling capture writes bounded diagnostic events to Logs/Framelet/Scrolling/ under the user Library directory (inside the app container in sandboxed builds) without pixels, page text, or keystrokes. Rejected-frame PNGs are saved there only if you explicitly enable failure-frame debugging. You can manage saved files and local logs in Finder.

External services and actions you choose

If subscriptions become available, Apple StoreKit and your Apple account handle product display, purchases, renewals, and restoration; the developer does not receive payment card numbers. When native translation is unavailable, the app copies the source text and opens the Google Translate home page only after you choose web translation. It does not put the text in a URL or submit it automatically. Content you later paste into a third-party site is governed by that site's privacy policy.

Website and support

GitHub Pages hosts this website. GitHub may process visit data under its privacy statement. This website embeds no third-party analytics scripts. GitHub Issues are public: do not post screenshots, recordings, account details, transaction records, or other sensitive information.

Your choices and contact

You may revoke Screen Recording, Accessibility, or Microphone access in macOS System Settings, stop using the corresponding features, and manage locally saved files. Manage subscriptions through your Apple account. Contact the developer about this policy through the support page. If the released app's data handling changes, we will update this page and the App Store privacy information.
