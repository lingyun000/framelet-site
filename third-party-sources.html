English

Source and build details

Framelet WebM export uses FFmpeg under LGPLv2.1 or later, plus libvpx and Opus under their respective licenses. The links above point to official upstream source releases corresponding to the current Apple silicon encoder candidate; SHA-256 checksums are provided for the downloaded archives. This page contains no private Framelet application source.

Set MACOSX_DEPLOYMENT_TARGET=14.0. Build libvpx 1.16.0 for arm64-darwin20-gcc with --disable-shared --enable-static --disable-examples --disable-tools --disable-docs --disable-unit-tests --disable-vp8 --enable-vp9 --disable-vp9-decoder. Build Opus 1.6.1 with --disable-shared --enable-static --disable-extra-programs --disable-doc. Compile FFmpeg 8.1.1 with:

--disable-gpl --disable-nonfree --disable-version3 --disable-autodetect --disable-doc --disable-debug --disable-ffplay --disable-ffprobe --disable-devices --disable-network --disable-hwaccels --enable-static --disable-shared --enable-libvpx --enable-libopus --disable-everything --enable-ffmpeg --enable-protocol=file --enable-demuxer=mov --enable-muxer=webm --enable-decoder=h264,aac,pcm_s16le,pcm_f32le --enable-parser=h264,aac --enable-encoder=libvpx_vp9,libopus --enable-filter=scale,format,aformat,aresample,anull,null --enable-bsf=vp9_superframe --enable-swscale --enable-swresample

Use pkg-config entries that link directly to the built libvpx.a and libopus.a, so the helper does not depend on package-manager dynamic libraries. The app communicates with the encoder as a separate process. The candidate encoder SHA-256 before code signing is a4a65c49b2991df3b3fae9a2384300d16ce1b6d3dd03e1b9e801f3caad962414. License texts are available here: FFmpeg LGPL 2.1, libvpx license, libvpx patent notice, and Opus license. The same texts accompany the app bundle. Source and build details will be updated if the distributed binary changes.
